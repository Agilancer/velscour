# VELSCOUR — Collection 05: Monk, Rogue, Ninja

144 new armor sprites, 48 per class: eight of each Common, Uncommon, Rare, Epic, Legendary and Mythic. Built-in image generation used actual original approved VELSCOUR sprites as references. One eight-outfit sheet at a time; one Monk Uncommon outfit was edited to replace clothing too similar to the default. Initial rejected sheet/outfit excluded; the other seven outfits retain native extracted art. No existing collection overwritten.

artwork/ contains 144 native transparent PNGs. source_sheets/ preserves 17 initial full-quality sheets plus the corrected single-outfit source. armor_sheets/ contains 18 transparent 1536x1024 presentation sheets, four columns by two rows, eight designs each. class_sheets/ contains three transparent 1536x1536 sheets, eight columns by six rows: Common to Mythic top-to-bottom, variants 01-08 left-to-right. identity_anchors/ contains each class default and a head crop used for continuity. prompts/ preserves exact prompts including correction. DESIGN_CARDS lists actual saved files; VISUAL_REVIEW records all 18 completed batches.

Monk: bald man, yellow ochre/saffron garb, large prayer beads. Rogue: adult woman with short black hair and black leather gear. Ninja: full black hood and face wrap with only an eye slit, explicitly overriding the generic uncovered-head rule. Their combat weapons are not drawn in these body-armor sprites; all hands are empty.

Native source art stays separate from resized presentation atlases. Review includes full source and isolated sprites for identity/anatomy/pose, supported construction/repeated patterns/materials, actual approved style comparisons, and 60px-height display reads. FINAL_FILE_CHECKS measures each saved PNG's dimensions, transparency, color count and hash. SAVED_ATLAS_CHECKS records disk-reopened dimensions, alpha and cell/baseline clearance for all 21 sheets and 288 placements. Hash uniqueness is not alone proof of visual originality.

This is high-quality SOURCE ART, not a certified palette-limited game export. Canonical 128x192 AP landmarks, flat integer AP blocks, pixel-identical head regions, 16/20/24-color budgets, binary alpha and runtime alignment are NOT certified. No game importer/rig was supplied or executed. Shared locks are art direction, with current Ninja identity and requested sheet layout taking precedence.
