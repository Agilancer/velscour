Now write the VELSCOUR STYLE LOCK documents, so that any future chat (or another artist) can reproduce exactly this

vague adjectives. Produce them as downloadable files:

1. STYLE_LOCK.md, with these sections:
   a. Style name and a 5-sentence definition of GRIM NOCTURNE, and what it takes from Diablo II, Symphony of the
      Night and Final Fantasy VI (craft only, never content).
   b. Grid and sizes: the art pixel, the 128x192 hero frame, the 108-AP hero, every landmark coordinate of the pose
      lock, the delivery scales (2x armor, 3x overlays, 4x pose masters), and the art-pixel heights of every asset

   d. The palette: every ramp with hex values, colour budgets per asset type, the 60/30/10 rule, which ramps each of

   g. Rarity ladder with concrete design vocabulary for each rarity.
   h. Class bible: for all 16 classes, the hero's face, hair, skin, build, underlayer colours and the motif family

   j. World rules: townsfolk, monsters, bosses, pets and biomes in this style (density, palette, light, contrast

   l. A "reproduction recipe": the exact order of prompts and attachments that recreates this style from scratch.

2. ARMOR_PROMPT_TEMPLATE.txt: one long fill-in-the-blanks prompt for 5 body armors of any class (with blanks for

3. OVERLAY_PROMPT_TEMPLATE.txt: the same for helmets, gloves and boots sheets.

4. WORLD_PROMPT_TEMPLATES.txt: the same for townsfolk, enemies, bosses, pets and biome sheets.

5. CLASS_CARDS.md: one card per class: identity line, palette ramps with hex, motif family, 10 armor ideas across

Rules for the documents: plain markdown/text, no images inside them, every number consistent with the master
prompt. Where you add something new, mark it "(added)" so I can review it.
